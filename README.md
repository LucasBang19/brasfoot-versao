# brasfoot-versao

Lista de versões lida pelo botão **Verificar atualização** da tela inicial do SuperBrasfoot 2.8 e PRO.

O jogo baixa `versao.txt` deste repositório e compara o número de build publicado com o do APK instalado.
Uma linha por edição: `pacote|versionCode|nome da versão|link de download|novidades`.

Para publicar uma versão nova: suba o APK assinado (Releases deste repositório, MediaFire ou site), depois
edite a linha da edição em `versao.txt` com o build novo e o link.
